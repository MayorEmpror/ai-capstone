# AI Capstone Project

An AI-assisted software development project demonstrating modern engineering workflows.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- [PostgreSQL](https://www.postgresql.org/)
- npm, pnpm, or yarn

### Setup

Application scaffolding is in progress. Once the Next.js project is initialized, setup will be:

```bash
git clone <repository-url>
cd week1
npm install
cp .env.example .env   # configure your database URL
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
